# 本地 HTML 交付规范

选择 `local-html` 时读取。目标是把完整复习工作台交付成可以直接打开的文件，不要求用户运行命令。

## 产物

默认交付 `复习工作台.html`，附简短的 `本地使用说明.md`。开发源代码可以拆文件，但最终交付必须自包含：课程数据、深度正文、题库、样式和交互都放进 HTML。不得把一个仍引用外部 `data.js` 的入口称为单文件版。

若用户明确要求保留多文件或材料体积确实不适合内嵌，说明原因并交付完整文件夹 ZIP；注明必须先解压、保持目录结构。不能默默改变单文件承诺。

## 构建要求

- 核心学习功能不使用远程字体、CDN、联网 API、远程数学渲染器或 `fetch()` 读取本地 JSON。
- 需要图表或公式时，使用内嵌 SVG、MathML 或随包提供的离线渲染依赖。原始 PDF 链接只作可选来源，不成为读懂正文的前提。
- 不依赖 `type="module"` 的跨文件导入。将数据与正文按依赖顺序内嵌；处理数据中的 `</script>` 等边界，正文仍按安全文本或受控格式渲染，不能直接执行课程文本。
- 单文件版移除外部 manifest 和 Service Worker 注册；不应出现缺文件请求。Vercel/PWA 代码只在对应输出中启用。
- 沿用工作台 UI，保留完整讲解、例子、错因和题库；交付方式不构成压缩内容的理由。
- 新课程使用独立、稳定的课程 ID 与存储命名空间；重新生成同一课程时保留兼容状态，不清空旧学习记录。

## 进度与备份

文件本身不会因为浏览器作答而自动改写。可以尝试用 `localStorage` 保存，但 `file:` 页面的行为没有跨浏览器保证；移动、重命名 HTML、换浏览器或使用隐私模式后，记录可能不可见或不持久。

- 捕获读取和写入失败，当前会话仍能学习；提示“当前环境无法持久保存，请导出记录”，不能静默声称已保存。
- 提供 JSON 导出，包含课程 ID、内容版本、记录版本和题目 ID，明确这是学习记录备份，不是另一份网页。
- 若实现导入，校验格式、大小、课程 ID 和题目兼容性，展示合并或替换影响，保留旧记录再操作；不能把未知文件内容当代码执行。
- 若尚未实现导入，说明导出供 AI 后续读取，不能宣称已有一键恢复、换设备同步功能。

## 验收

直接打开最终交付文件，不以 `localhost` 验证替代 `file://` 验证：

1. 断网打开首页、各单元深度正文和题库。
2. 完成一题、标记不确定、进入复习队列，检查草稿与重做。
3. 刷新及重新打开，记录该浏览器的保存结果；失败时确认提示和导出可用。
4. 下载并解析导出 JSON；如有导入，验证错误文件拒绝和旧记录保护。
5. 检查页面无必须联网的资源、无缺少伴随文件的错误，记录实际浏览器和未验证项。

## 给用户的使用说明

使用本次真实文件名和位置写明：下载到固定文件夹 → 用 Chrome、Edge 或 Safari 等浏览器打开 → 学习和排查 → 定期导出复习记录。若双击打开的是代码编辑器，使用“打开方式”选择浏览器。不要求注册 Vercel。

收到文件的其他人获得课程内容，不会自动获得原用户浏览器里的进度。手机文件预览器未必执行网页交互；希望稳定通过链接访问时，可以再选择 Vercel 版。
