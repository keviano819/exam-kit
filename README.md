# Exam Kit

把你的课程 PPT、讲义和笔记，做成一套期中／期末复习工作台：深入讲解知识、做题检查理解，再针对薄弱点继续复习。

## 1. 安装

在支持 skill 安装、文件读写和脚本执行的 AI 助手中，发送：

```text
请检查并安装这个 skill：https://github.com/keviano819/exam-kit
请安装完整目录，不要只下载 SKILL.md。
```

Exam Kit 已内置教学规则和工作台模板，不需要另外安装 `ko-lesson`。生成工作台需要 AI 的运行环境具备 Python 3.9+；打开生成后的网页不需要。

## 2. 提供课件，开始复习

安装后，上传课程材料或提供本地文件路径，再告诉 AI 你的复习目标：

```text
使用 exam-kit，帮我准备理论语言学期中考试。
这是我的 PPT，考试范围是第 1–4 章。
请讲清楚概念、例子、易混点和适用条件，不要只做摘要。
```

如果知道考试日期、题型或自己最不熟的部分，也一起说明。AI 会先整理材料范围和学习路线，再生成讲解与练习。

默认先做第一单元，根据你的反馈继续。希望一次生成全部内容时，直接补充：

```text
请一次性生成考试范围内的全部学习单元，保留详细讲解和练习。
```

## 3. 选择使用方式

| 你想怎么使用 | 告诉 AI | 你会拿到 |
| --- | --- | --- |
| 在电脑上本地复习 | “做成本地 HTML” | 一个可用浏览器直接打开的 HTML 文件，无需注册或部署 |
| 在手机上打开，或分享链接 | “做成 Vercel 手机访问版” | 发布 ZIP 和从注册、上传到更新的详细教程 |

两种方式使用相同的课程内容和工作台。选择手机版后，按教程手动完成登录、验证和上传，再把生成的网址发给 AI 验收即可。

## 4. 在工作台中学习

先在「学习路线」阅读讲解，再进入「知识排查」作答。答错或标记“不确定／不会”的题会进入「薄弱点与错题」，可以回看讲解并重做。主观题先写答案，再对照要点自评。

需要 AI 补讲时，在「薄弱点与错题」导出复习记录，把文件发回对话：

```text
这是我的复习记录。请分析我没掌握的概念，换个例子讲清楚，
再出几道变式题。已经掌握的部分不用重复讲。
```

学习记录保存在当前浏览器，不会自动跨设备同步。网页本身不调用 AI；补讲和新题在对话中生成。分享前请确认材料可以公开，不要上传个人学习记录。
